# Synthetic daily-record fixtures

These files are format examples, not a person’s records or recommendations. Each JSON file is a versioned backup for its named module. Use that module’s **Import JSON backup**, inspect the records, then choose **Replace with reviewed backup**; this replaces its current ledger.

Expected examples: active vitamin D label totals combine to 30 mcg/day; the eaten meal contributes 300 kcal and 15 g protein while fiber remains unknown; the planned snack is excluded. The completed workout contributes 30 minutes and 200 kg·reps of external-load volume; the planned workout and bodyweight mass are excluded. The CGM file aligns with the eaten meal and produces a 5 mmol/L pre-meal mean and 8 mmol/L observed peak under the stated quality gates.
